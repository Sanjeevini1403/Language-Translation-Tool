# Language Translation Tool

An AI-powered language translation tool built using Python and Streamlit.

## Features
- Translate text between multiple languages: English, Tamil, Hindi, French, Malayalam, German, Japanese
- Swap source/target language with one click
- Modern dark-themed, gradient UI
- Live character count
- Instant translation output

## Technologies Used
- Python
- Streamlit
- Googletrans

## How to Run
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the app:
   ```
   streamlit run app.py
   ```
